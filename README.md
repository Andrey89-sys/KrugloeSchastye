# АИС "Круглое счастье"

Автоматизированная информационная система управления сетью ресторанов быстрого питания

## 📋 Описание

Система предназначена для автоматизации деятельности сети ресторанов, включая:
- Учёт заказов (в зале, по телефону, через веб-интерфейс)
- Управление меню и рецептурным составом блюд
- Складской учёт ингредиентов
- Взаиморасчёты с поставщиками
- Начисление заработной платы персоналу
- Программу лояльности (дисконтные карты, подарочные сертификаты)
- Аналитическую отчётность

## 🛠 Технологический стек

- **Платформа**: 1С:Предприятие 8.3
- **Режим**: Управляемое приложение
- **Интерфейс**: Такси
- **СУБД**: PostgreSQL / Встроенная СУБД
- **Архитектура**: Клиент-серверная (3-уровневая)

## 📦 Основные подсистемы

1. **НСИ** - нормативно-справочная информация
2. **Продажи** - управление заказами
3. **Склад и закупки** - учёт товаров
4. **Зарплата и кадры** - расчёт с персоналом
5. **Программа лояльности** - дисконтные карты и сертификаты
6. **Отчёты и анализ** - аналитическая отчётность на СКД

## 👥 Роли пользователей

- Менеджер ресторана
- Повар
- Официант
- Курьер
- Бухгалтер
- Директор ресторана
